# Backlands Farming

Jogo online de fazenda com sistema de batalha secundário, em tiles de **16x16 px**.

| Peça | Base | Situação |
|---|---|---|
| Servidor | [forgottenserver-downgrade-1.8-8.60](https://github.com/Mateuzkl/forgottenserver-downgrade-1.8-8.60) (TFS 1.8, protocolo 8.60) | em estudo |
| Map editor | [NexaMap-Editor](https://github.com/Mateuzkl/NexaMap-Editor) | em estudo, precisa de suporte a 16px |
| Editor DAT/SPR | [Backlands Asset Studio](object-editor/README.md), inspirado no ObjectBuilder | editor desktop 8.60 com sprites nativos 16×16 |
| Cliente | Web (a definir) — [AstraClient](https://github.com/Mateuzkl/AstraClient) só como referência, **não versionado** | planejamento |
