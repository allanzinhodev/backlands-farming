# Backlands spells

The single Farmer vocation keeps basic healing (`exura`, `exana pox`), light
(`utevo lux`), travel (`utani hur`, `exani tera`), one physical attack
(`exori ico`) and the four house commands. These abilities require no premium.

The Tibia creatures and their 27 spell files were removed separately. Their
explosion, stalagmite and stone shower runes are no longer needed. This cleanup
removes 231 player spell, rune-conjuring and party files in total.

Core Lua APIs stay in place for compatibility; C++ subsystem removal is deferred.
